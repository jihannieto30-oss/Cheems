# Glosario

Palabras que aquí significan algo concreto. Si una nota usa una de éstas, quiere
decir esto y no otra cosa.

| término | qué es |
|---|---|
| **PEPTIDEX** | la marca |
| **PepX** | la aplicación. Vive en `web/pepx/`, es un solo fichero HTML instalable |
| **la tienda** | `web/PEPTIDEX.html`, el catálogo público. Otro producto, otro fichero |
| **PepCheems** | el asistente dentro de PepX. Intérprete determinista sobre datos locales — **no** un modelo de lenguaje |
| **Doc.Peps** | el motor de observaciones que PepCheems usa para comentar métricas |
| **protocolo** | una **pila con nombre**: N compuestos con su dosis, más frecuencia, inicio y hora comunes |
| **registro de operación** | `web/assets/library.json`, las 60 fichas de compuesto. Se **cita**, no se aplica |
| **las tres líneas** | FITNESS, BEAUTY, LONGEVITY |
| **RUO** | *research use only*. Solo uso en investigación. El encuadre legal de todo |
| **la raya** | el límite que PepCheems no cruza: no dice qué tomar, cuánto ni cada cuándo |
